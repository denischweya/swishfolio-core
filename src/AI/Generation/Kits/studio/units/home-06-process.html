How we work

From first spark to opening night.

Four stages, the same on a six-week film and a nine-month installation. You always know which one we are in.

  1. 011–2 weeks

    Spark

    We find the one idea worth making and test it as moving sketches, not slides.

    Concept films · mood loops

  2. 022–4 weeks

    Shape

    Look development, storyboards and technical tests, so nothing surprises anyone later.

    Look dev · boards · tech tests

  3. 034–10 weeks

    Make

    Shoot, build, render and code in parallel, with a weekly screening you are always invited to.

    Production · weekly screenings

  4. 04Launch week

    Open

    Grade, mix, install and switch on. We stay for the opening and the first week after.

    Delivery · install · support
