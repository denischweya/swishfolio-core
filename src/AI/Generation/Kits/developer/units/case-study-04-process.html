02The approach

Four decisions that did the heavy lifting.

  1. 01

    A ledger before features

    Every cent moves as a pair of ledger entries in Postgres, so balances can be rebuilt from history and audited at any time.

  2. 02

    Idempotent by default

    Every write carries an idempotency key. Retries, double clicks and replayed webhooks can never pay a seller twice.

  3. 03

    An outbox, not a hope

    Events are written in the same transaction as the money, then delivered by workers. Nothing is lost when a bank rail is down.

  4. 04

    Migrate in cohorts

    Sellers moved in small groups behind a flag, with the old batch job running in parallel until every cent matched.
