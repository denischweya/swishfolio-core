// what i build

Five things teams hire me for.

One engineer across the whole stack, which means no handover gap between the API and the interface and no architecture decision made by committee.

// 01 · product build

Whole products, schema to ship

Data model, API, interface, pipeline and the runbook that explains it. One engineer accountable for the whole path to production, so nothing gets lost between the front end and the infrastructure. Typical build: ten to fourteen weeks, with something demoable in week two.

// 02 · rescue work

Legacy systems, made boring

I take on the service nobody wants to touch. Tests and traces first, then small reversible refactors while it keeps serving live traffic.

// 03 · apis

APIs built to be integrated

Typed REST and webhooks with idempotency keys, cursor pagination, replayable events and reference docs generated from the schema.

// 04 · interfaces

Front ends with a budget

React and Next.js held to real numbers: Lighthouse 95 or better, no layout shift, and a component library your designers can read.

// 05 · platform

Deploys that stop being events

Docker, Kubernetes and GitHub Actions wired so a merge reaches production in nine minutes, with a rollback you have actually rehearsed.
