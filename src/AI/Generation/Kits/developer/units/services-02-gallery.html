01 / 04

Product engineering

I take a product from schema to production: data model, API, interface, tests and the pipeline that ships it. You get a working build every week, not a big reveal at the end.

  • Architecture and data modelling
  • React and Next.js front ends
  • APIs in TypeScript or Go
  • CI/CD, preview environments and monitoring

Typical engagement: 8 to 16 weeks

02 / 04

Platforms & APIs

Some systems have to be right every time. I design APIs and back-end platforms around correctness first: idempotent operations, auditable data and failure modes you have tested on purpose.

  • API design, versioning and docs
  • Ledgers, payments and webhooks
  • Event-driven pipelines and queues
  • Load testing and capacity planning

Typical engagement: 10 to 20 weeks

03 / 04

Performance & reliability

When an app is slow or fragile, guessing is expensive. I start with measurement (traces, profiles, real user data), fix the few things that matter most and leave dashboards behind so it stays fixed.

  • Performance and Core Web Vitals audits
  • Database and query tuning
  • Observability with OpenTelemetry
  • Incident reviews and runbooks

Typical engagement: 2 to 6 weeks

04 / 04

Fractional tech lead

For teams without a senior engineer, or between hires. I review architecture, unblock pull requests, help you hire and mentor the team, so decisions get made well and quickly.

  • Architecture reviews and tech roadmap
  • Code review and pairing
  • Hiring loops and interviews
  • Mentoring for mid-level engineers

Typical engagement: 3 months, renewable
