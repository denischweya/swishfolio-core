// how i think about the work

Four things I will not compromise on.

// 01

Boring beats clever

The next person to read this code will be tired and under pressure. I write for them, not for the version of me that enjoys a clever abstraction.

// 02

Measure before arguing

Every performance claim on this site has a number behind it because the first thing I do is instrument the thing. Opinions are cheap; traces are not.

// 03

Security is a day-one decision

Auth model, audit trail and data retention get designed with the schema. Retrofitting them into a live fintech product is a quarter nobody budgeted for.

// 04

Leave with the lights on

A good handover means your team ships their next feature without messaging me. If I am still the only person who understands it, I did the job badly.
